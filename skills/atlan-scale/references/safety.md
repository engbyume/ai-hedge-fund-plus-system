# Safety reference

The default posture is research-only. A generated suggestion is not an order, and an order plan is not proof of execution.

Block external action when any of these is true:

- benchmark or baseline is missing for a performance claim
- account or platform availability is unverified
- a source is stale or contradictory
- a candidate lacks a catalyst, countercase, or invalidation
- a sell has no paired buy or approved proceeds-hold instruction
- dependent cash has not settled
- the operator has not explicitly confirmed the action
