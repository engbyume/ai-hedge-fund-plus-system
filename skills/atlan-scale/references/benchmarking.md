# Benchmarking reference

Declare the benchmark and baseline before viewing the result. Use a consistent return method, cash-flow normalization, dividend treatment, cost treatment, and trading-day calendar. Record the benchmark proxy and the retrieval source.

At minimum, publish daily, weekly, monthly, cumulative, drawdown, and downside-capture fields when the data window supports them. A small positive spread is not meaningful without a comparable date range and uncertainty context.
