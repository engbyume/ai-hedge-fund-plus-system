# Security and responsible use

Do not put credentials, account exports, broker tokens, email tokens, cookies, or private reports in this repository. Use a private local runtime and environment variables for secrets.

This project is research software and does not provide investment advice. It is not designed to guarantee returns, prevent losses, or execute trades safely without independent review. Keep live trading disabled unless the operator has separately audited the integrations and explicitly enabled them.

If you discover a secret in the repository, revoke it immediately, remove it from the public history using the provider's documented procedure, and open a private report to the repository owner. Do not post the secret in an issue.
