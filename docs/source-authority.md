# Source authority

Use this hierarchy when sources disagree:

1. Direct operator confirmation for personal holdings, constraints, and decisions.
2. Live authorized account readback for account values and settlement.
3. Primary company, exchange, regulator, or model-project source for facts.
4. Dated archived report for historical system output.
5. Secondary commentary for discovery only, never as sole proof.
6. Forecast or sentiment output as supporting evidence, never as authorization.

Every public claim should be mapped to a row in [`evidence/source-register.md`](../evidence/source-register.md) with a status and freshness note.
